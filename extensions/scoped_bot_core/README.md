# Scoped Bot Core

这是独立的脱敏逻辑组件，不会因导入而连接微信、模型或网络，也没有接进旧机器人的运行配置。

- 稳定账号、会话、成员和消息身份；显示名不充当权限。
- SQLite inbox 去重与原子领取、持久 outbox 意图；unknown 不能自动重获发送资格。
- 有界上下文检索与时间预算、带证据的成员记忆、更正和撤回。
- 版本化人格核心和加密继承包；导入只返回惰性数据，不执行内容。
- 显式公共网页/表情检索意图、本地敏感查询拒绝及受限图片缓存。
- 同一次模型回答中的文字/表情提案解析、轻松场景校验，以及审核图片的来源和内容指纹绑定。

这里不包含实际账号、联系人、群配置、人格正文、记忆库、聊天、凭据、截图、VM脚本或宿主控制。`live_selftest.py` 是可注入的合成发送契约，单独使用它不会运行真实客户端。图片缓存不等于微信已发送图片，真实发送需要独立可信传输层与回执。

## 验证

在本目录创建隔离 Python 3.12 环境后：

```sh
python -m pip install -e ".[test]"
python -m unittest discover -s tests -q
```

测试只使用合成账号、消息、密钥和临时数据；HTTP与图片响应由测试注入，不需要真实API key或登录微信。示例密钥仅供测试，不能用于部署。

公共检索只传调用者明确给出的关键词；可选自动反应只接受固定公开情绪词，由调用者提供经过检查的图片目录及发送前校验，不应把完整聊天、成员资料或记忆拼进查询。结果标题/摘要/链接是不可信数据，不能提升为工具指令。使用公开图片仍需尊重来源和授权。

## 运维与通道边界

进程运行不等于登录/解锁、采集、模型与发送回执都健康。GUI代理需要有效交互桌面；掉线后的未知发送只核对，不重发。跨端身份应包含platform/account/chat/member，默认不合并同名成员。

云端部署、远程桌面断开、Session 0、登录恢复及周期备份需要单独演练；这个模块不是24小时托管服务或自动登录器。配置先验证、留快照、停止并清空正在执行动作，再应用/读回/回滚。不要把密钥、登录态、原始聊天或运行数据库提交Git；私有仓库也不应存明文凭据。

本目录沿用父仓库 GPL-3.0-or-later。没有复制AstrBot、MaiBot、微信自动化库等上游实现源码，也不把其许可证改标为本目录许可证。来源快照文件仅记录自身组件内容指纹，不包含私有运行状态。

自动反应模块没有默认图片目录或发送器；它不会因为导入而搜索、下载或发图。调用者仍须实现持久的群级冷却、确认文字间隔、总期限及单一最终动作。目录元数据和格式校验不能代替检查实际图片内容，也不声明图片授权。
